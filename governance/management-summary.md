# Management summary

The MagicWorks Knowledge & Resource Centre is a structured public knowledge layer designed to support search visibility, AI retrieval, buyer education and commercial discovery.

## Operating model

* Main website = commercial canonical surface.
* Knowledge centre = explanatory/reference surface.
* GitHub = source of truth for public knowledge content.
* GitBook = publishing and retrieval interface.
* GA4 + GSC + Bing + lead/CRM data = measurement stack.

## Launch architecture

Four GitBook sections:

1. Home
2. Knowledge Centre
3. Help Centre
4. Changelog

The initial knowledge set covers the five MagicWorks pillars plus SEO/AEO/GEO, AI Search Visibility, AI automation, buyer guidance and case-study learning.

## Guardrails

* No guaranteed AI citations.
* No confidential commercial data in the public repo.
* No internal UTM parameters between owned MagicWorks web properties.
* Advisory and delivery boundaries stay explicit.
* AI-assisted drafts require factual verification.

## Review cadence

Track baseline, 30, 60 and 90-day signals, then move to monthly maintenance.
