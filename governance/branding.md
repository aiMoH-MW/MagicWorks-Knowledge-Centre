# MagicWorks Knowledge Centre branding

Use the current MagicWorks website as the source of truth for brand styling.

## Approved brand tokens

- Indigo: `#2A1B5C`
- Violet: `#5B3FBE`
- Gold: `#D4A537`
- Ivory: `#F7F3EA`
- Graphite: `#1A1A22`
- Pale violet: `#EDE9F7`

## Typography

- Headings: Source Serif 4 where supported
- Body/interface: Inter where supported

If the GitBook plan does not support custom fonts, prefer a restrained serif heading / clean sans-serif body pairing that remains close to the website rather than forcing an unrelated font.

## Approved logo assets

Repository copies:

- `assets/branding/logo-header.webp`
- `assets/branding/logo-footer.webp`
- `assets/branding/favicon.ico`

Use the header logo in the published-site header where the plan allows it.

Use the footer logo only if it remains legible and does not create unnecessary visual weight.

Use the approved favicon rather than generating a new icon.

## Navigation

Recommended header links:

- MagicWorks → https://magicworksitsolutions.com/
- Services → https://magicworksitsolutions.com/services
- Work → https://magicworksitsolutions.com/work
- Knowledge → the Knowledge Centre section
- Contact → https://magicworksitsolutions.com/contact

Do not add internal UTM parameters to these owned-site links.

## Visual direction

Use a clean B2B knowledge presentation:

- light/ivory reading background where possible;
- indigo/violet as primary brand accents;
- gold only as a restrained accent;
- high contrast and strong readability;
- avoid decorative gradients or effects that compete with the documentation.
