# Launch and page QA checklist

## Content

- [ ] One clear primary intent
- [ ] Direct answer near the top
- [ ] No confidential information
- [ ] No unsupported guarantees
- [ ] Current service scope verified
- [ ] Advisory vs delivery boundary correct
- [ ] Spelling, grammar and terminology reviewed

## Structure

- [ ] Page appears once in `SUMMARY.md`
- [ ] Relative links resolve within the same space
- [ ] Cross-space links use a supported final URL after spaces exist
- [ ] No orphan pages intended for public navigation

## Search and AI

- [ ] Unique title/topic
- [ ] Useful description frontmatter
- [ ] Clear headings
- [ ] Important entities named explicitly
- [ ] Claims boundaries visible

## Commercial journey

- [ ] Relevant main-site link added where appropriate
- [ ] No internal UTM parameters
- [ ] CTA does not overwhelm the informational role

## Technical

- [ ] Git sync succeeds
- [ ] No broken links
- [ ] Mobile rendering checked
- [ ] Indexing/canonical behaviour reviewed after publication
