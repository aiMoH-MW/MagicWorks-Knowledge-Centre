# Corrections and governance

The knowledge centre is maintained from a Git repository so material changes are versioned.

Public pages should:

* have a clear purpose,
* avoid confidential client or internal operating detail,
* distinguish guidance from guarantees,
* avoid unsupported claims,
* link to canonical commercial destinations where appropriate,
* and be updated when the underlying service model changes.

Significant structural or policy changes should be reflected in the Changelog.
