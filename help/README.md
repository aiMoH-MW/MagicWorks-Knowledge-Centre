# Help Centre

This section answers common questions about the MagicWorks Knowledge & Resource Centre.

## Is this the main MagicWorks website?

No. The main website remains the canonical commercial destination. This knowledge centre provides deeper explanatory and reference material.

## Is everything here a service MagicWorks sells?

No. Some pages explain concepts, frameworks or buyer decisions. Current commercial services are defined on the main MagicWorks website and in approved proposals.

## Are AI-search citations guaranteed?

No. No agency controls whether an AI system cites or surfaces a particular source. MagicWorks focuses on improving structure, authority, accessibility and measurement.

## How are corrections handled?

Material corrections should be updated in the source repository and reflected through Git Sync. Significant public changes can also be noted in the Changelog.
