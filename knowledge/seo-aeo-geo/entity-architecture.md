# Entity architecture

Entity architecture defines the important things an organisation wants to be understood for and the relationships between them.

Typical entities include the organisation, experts, services, products, programmes, locations, methodologies and subject areas.

A useful entity map answers questions such as:

* What is this organisation?
* What does it offer?
* Who is responsible for the expertise?
* Which topics does it have evidence to speak about?
* How do products, services and resources relate?
* Which pages are canonical for each concept?

Entity architecture is not a schema-markup exercise alone. It begins with information clarity, then technical signals reinforce that clarity.
