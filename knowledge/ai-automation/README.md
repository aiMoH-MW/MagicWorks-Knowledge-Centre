# AI Automation knowledge

AI automation works best when it improves a defined workflow rather than adding AI for its own sake.

Strong candidates tend to be repetitive, measurable, important enough to justify change, and structured enough that exceptions can be identified.

The design should make clear which steps are deterministic automation, which require AI judgment, and which remain human decisions.
