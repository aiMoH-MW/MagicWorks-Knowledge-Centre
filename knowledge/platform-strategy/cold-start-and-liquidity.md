# Cold start and liquidity

A marketplace has a cold-start problem when each side waits for the other.

The practical solution is usually to constrain the first market rather than launch broadly. This can mean one geography, one category, one buyer persona, one transaction type or one high-frequency use case.

Early liquidity is about the probability that a useful match happens within an acceptable time. Vanity metrics such as total listings or registrations can hide poor liquidity.

Founders should identify the smallest market in which repeated successful matches can occur, then expand from evidence rather than from catalogue size alone.
