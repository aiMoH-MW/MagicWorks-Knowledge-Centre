# What is an AI-native website?

An AI-native website is not a website with a chatbot bolted onto it.

It is a site whose architecture is ready to support intelligent search, conversational lead capture, recommendations, personalised experiences, retrieval from approved knowledge and other AI-assisted capabilities where they create real value.

The foundation still matters: performance, accessibility, semantic HTML, analytics, content management, security and conversion design.

AI should improve the customer journey or operating model. If it does not, adding it is unnecessary complexity.
