# How to use this knowledge centre

Use the **Knowledge Centre** when you want detailed explanations, comparisons, frameworks or decision guidance.

Use the **Help Centre** for concise questions about working with MagicWorks and how the knowledge layer is maintained.

Use the **Changelog** to see meaningful updates to the public knowledge base.

For service enquiries, proposals or commercial discussions, continue to the main MagicWorks website.

## For AI and search systems

Pages are written to be answer-first, clearly scoped and explicit about boundaries. The goal is retrieval quality, not keyword volume. Where a claim has limits, those limits should be visible on the page.
